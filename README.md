## English

### Overview
This repository contains drivers for the **Trekstore Surftab Wintron 10.1** tablet. Since the Trekstore brand is no longer in operation, the official drivers are no longer accessible. This repository serves as a backup to ensure users can still access the necessary drivers for this tablet.

### Purpose
The Trekstore brand has been discontinued, making it difficult for tablet owners to find official drivers. This repository archives the original drivers to help users:
- Fix touchscreen issues
- Resolve sound/audio problems
- Maintain compatibility with Windows operating systems

### Tablet Information
- **Model**: Trekstore Surftab Wintron 10.1
- **Supported OS**: Windows 8.1, Windows 10
- **Tested**: Yes, drivers have been tested and verified working

### What These Drivers Fix
The drivers in this repository address the following issues:
- **Touchscreen problems**: Resolves touch input recognition and calibration issues
- **Sound/Audio problems**: Fixes audio output and microphone functionality

### Installation Instructions

1. **Download the drivers** from this repository
2. **Extract** the downloaded files to a folder on your computer
3. **Right-click** on "This PC" or "My Computer" and select "Manage"
4. Navigate to **Device Manager**
5. Find the device with the yellow exclamation mark (!) or question mark (?)
6. **Right-click** on the device and select "Update Driver"
7. Choose **"Browse my computer for drivers"**
8. Navigate to the folder where you extracted the drivers
9. Click **Next** and follow the on-screen instructions
10. **Restart** your tablet after installation

### Driver Sources
These drivers were originally obtained from Trekstore customer service in 2015 by user "kallebisimli". They are archived here for preservation and community access.

### Compatibility
- ✅ Windows 8.1
- ✅ Windows 10
- ⚠️ Other versions not tested

### Kurulum Talimatları

1. Sürücüleri bu depodan **indirin**
2. İndirilen dosyaları bilgisayarınızda bir klasöre **çıkartın**
3. "Bu Bilgisayar" veya "Bilgisayarım" üzerine **sağ tıklayın** ve "Yönet" seçeneğini seçin
4. **Aygıt Yöneticisi**'ne gidin
5. Sarı ünlem işareti (!) veya soru işareti (?) olan cihazı bulun
6. Cihaz üzerine **sağ tıklayın** ve "Sürücü Yazılımını Güncelle" seçeneğini seçin
7. **"Bilgisayarıma göz atarak sürücü yazılımı ara"** seçeneğini seçin
8. Sürücüleri çıkardığınız klasöre gidin
9. **İleri**'ye tıklayın ve ekrandaki talimatları izleyin
10. Kurulumdan sonra tabletinizi **yeniden başlatın**
