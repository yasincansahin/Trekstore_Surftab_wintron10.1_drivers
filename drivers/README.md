# Drivers Directory

This directory contains the drivers for the Trekstore Surftab Wintron 10.1 tablet.

## Directory Structure

### `/touchscreen`
Contains touchscreen drivers to fix touch input issues.

### `/audio`
Contains audio/sound drivers to fix audio output and microphone problems.

## How to Use

1. Navigate to the specific driver folder you need (touchscreen or audio)
2. Read the README.md in that folder for specific installation instructions
3. Follow the general installation guide in the main README.md

## Important Notes

- Always backup your system before installing drivers
- Create a system restore point
- Make sure you're installing the correct driver for your device
- Restart your tablet after driver installation

## Driver Information

These drivers are compatible with:
- Windows 8.1
- Windows 10

If you need drivers for other components (WiFi, Bluetooth, etc.), please check back later or open an issue in the repository.
