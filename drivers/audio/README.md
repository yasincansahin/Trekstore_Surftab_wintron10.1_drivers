# Audio Drivers

## Overview
This directory contains the audio/sound drivers for the Trekstore Surftab Wintron 10.1 tablet.

## Problem Solved
These drivers fix common audio issues including:
- No sound output
- Microphone not working
- Audio crackling or distortion
- Missing audio devices in playback/recording settings

## Installation

1. Extract the driver files (if compressed)
2. Open Device Manager (Right-click on "This PC" → "Manage" → "Device Manager")
3. Locate the audio device (usually under "Sound, video and game controllers" or with a yellow exclamation mark)
4. Right-click on the device and select "Update Driver"
5. Choose "Browse my computer for drivers"
6. Navigate to this folder
7. Click "Next" and follow the on-screen instructions
8. Restart your tablet after installation

## Compatibility
- Windows 8.1 ✅
- Windows 10 ✅

## Notes
- Create a system restore point before installation
- After installation, check Sound settings to ensure the correct playback/recording devices are selected
- You may need to adjust volume levels after driver installation

## Troubleshooting
If audio still doesn't work after installation:
1. Right-click the speaker icon in the system tray
2. Select "Playback devices"
3. Make sure the correct device is set as default
4. Test the device using the "Test" button

**Türkçe**

## Genel Bakış
Bu klasör, Trekstore Surftab Wintron 10.1 tablet için ses/audio sürücülerini içerir.

## Çözülen Sorun
Bu sürücüler yaygın ses sorunlarını giderir:
- Ses çıkışının olmaması
- Mikrofonun çalışmaması
- Ses çatlaması veya bozulması
- Oynatma/kayıt ayarlarında ses cihazlarının eksik olması

## Kurulum

1. Sürücü dosyalarını çıkartın (sıkıştırılmışsa)
2. Aygıt Yöneticisi'ni açın ("Bu Bilgisayar" → sağ tık → "Yönet" → "Aygıt Yöneticisi")
3. Ses cihazını bulun (genellikle "Ses, video ve oyun denetleyicileri" altında veya sarı ünlem işaretiyle)
4. Cihaza sağ tıklayın ve "Sürücü Yazılımını Güncelle" seçeneğini seçin
5. "Bilgisayarıma göz atarak sürücü yazılımı ara" seçeneğini seçin
6. Bu klasöre gidin
7. "İleri"ye tıklayın ve ekrandaki talimatları izleyin
8. Kurulumdan sonra tabletinizi yeniden başlatın

## Notlar
- Kurulum öncesi sistem geri yükleme noktası oluşturun
- Kurulumdan sonra, doğru oynatma/kayıt cihazlarının seçildiğinden emin olmak için Ses ayarlarını kontrol edin
- Sürücü kurulumundan sonra ses seviyelerini ayarlamanız gerekebilir

## Sorun Giderme
Kurulumdan sonra ses hala çalışmıyorsa:
1. Sistem tepsisindeki hoparlör simgesine sağ tıklayın
2. "Oynatma cihazları"nı seçin
3. Doğru cihazın varsayılan olarak ayarlandığından emin olun
4. "Test" düğmesini kullanarak cihazı test edin
