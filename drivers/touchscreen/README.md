# Touchscreen Drivers

## Overview
This directory contains the touchscreen drivers for the Trekstore Surftab Wintron 10.1 tablet.

## Problem Solved
These drivers fix common touchscreen issues including:
- Touch input not responding
- Inaccurate touch detection
- Calibration problems
- Multi-touch gesture issues

## Installation

1. Extract the driver files (if compressed)
2. Open Device Manager (Right-click on "This PC" → "Manage" → "Device Manager")
3. Locate the touchscreen device (usually under "Human Interface Devices" or with a yellow exclamation mark)
4. Right-click on the device and select "Update Driver"
5. Choose "Browse my computer for drivers"
6. Navigate to this folder
7. Click "Next" and follow the on-screen instructions
8. Restart your tablet after installation

## Compatibility
- Windows 8.1 ✅
- Windows 10 ✅

## Notes
- Create a system restore point before installation
- After installation, you may need to calibrate the touchscreen via Control Panel → Tablet PC Settings

**Türkçe**

## Genel Bakış
Bu klasör, Trekstore Surftab Wintron 10.1 tablet için dokunmatik ekran sürücülerini içerir.

## Çözülen Sorun
Bu sürücüler yaygın dokunmatik ekran sorunlarını giderir:
- Dokunmatik girişin yanıt vermemesi
- Yanlış dokunma algılama
- Kalibrasyon sorunları
- Çoklu dokunma jesti sorunları

## Kurulum

1. Sürücü dosyalarını çıkartın (sıkıştırılmışsa)
2. Aygıt Yöneticisi'ni açın ("Bu Bilgisayar" → sağ tık → "Yönet" → "Aygıt Yöneticisi")
3. Dokunmatik ekran cihazını bulun (genellikle "İnsan Arabirimi Cihazları" altında veya sarı ünlem işaretiyle)
4. Cihaza sağ tıklayın ve "Sürücü Yazılımını Güncelle" seçeneğini seçin
5. "Bilgisayarıma göz atarak sürücü yazılımı ara" seçeneğini seçin
6. Bu klasöre gidin
7. "İleri"ye tıklayın ve ekrandaki talimatları izleyin
8. Kurulumdan sonra tabletinizi yeniden başlatın

## Notlar
- Kurulum öncesi sistem geri yükleme noktası oluşturun
- Kurulumdan sonra, Denetim Masası → Tablet PC Ayarları yoluyla dokunmatik ekranı kalibre etmeniz gerekebilir
